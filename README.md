# Plateforme de recettes de cuisine

Projet final TP DWWM — Plateforme communautaire de partage de recettes de cuisine.

## Stack technique

- **Frontend** : React 18 + Vite + Bootstrap 5 + Sass
- **Backend** : Node.js + Express + Sequelize + MySQL
- **Auth** : JWT + bcrypt
- **Cache** : Redis
- **Tests** : Jest + Supertest
- **Déploiement** : Railway (API + BDD) + Vercel (frontend)
